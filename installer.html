Installe ECLYPTIA sur ton téléphone

Jeu d'action gratuit : survis aux vagues, bats les boss, joue seul ou à 3 avec tes amis.

JOUER MAINTENANT

Sur iPhone (Safari)

  1. Touche le bouton Partager ⬆︎ en bas de Safari.
  2. Choisis « Sur l'écran d'accueil ».
  3. Touche Ajouter : l'icône ECLYPTIA apparaît avec tes applications.

Si tu as ouvert ce lien dans une autre application (Snapchat, Instagram…), ouvre-le d'abord dans Safari.

Sur Android (Chrome)

  1. Touche INSTALLER LE JEU ci-dessus.
  2. Sinon : menu ⋮ de Chrome, puis « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Sur ordinateur

Le jeu est fait pour le téléphone. Ouvre cette page sur ton téléphone, ou joue ici dans ton navigateur.

  • 6 gardiens à débloquer
  • Boss mythiques
  • Jouable hors ligne
  • Groupe jusqu'à 3

Gratuit, sans compte et sans téléchargement lourd (16 Mo). Le jeu s'installe depuis le navigateur, pas depuis l'App Store ni Google Play.
